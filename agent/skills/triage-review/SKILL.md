# Triage review

Use this process when the requested outcome, authority, responsible person, or applicable Process Skill cannot be determined with sufficient confidence.

The opening checkpoint is human-owned and human-executed. Ask only for information needed to establish a concrete objective, deadline, and next Process Skill. Never silently discard or downgrade the intake.
